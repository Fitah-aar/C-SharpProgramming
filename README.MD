# C# Programming Course

Welcome to the C# Programming repository. This repository contains practical exercises,
assignments, and concept summaries for the C# Programming course using Visual Studio and the .NET Framework.

-------------------------------------

## Subject Outline

* **Course Title:** Visual C# Programming
* **Environment:** Microsoft Visual Studio (IDE)
* **Framework:** .NET Framework
* **Language:** C#

----------------------------------------

## Course Objectives

* Understand the fundamentals of Object-Oriented Programming (OOP) in C#.
* Learn how to design Graphical User Interfaces (GUI) using Windows Forms and controls.
* Master event-driven programming and writing event handlers.
* Develop clean, structured, and error-free code using Visual Studio IDE features like IntelliSense.
* Manage and version control C# projects using Git and GitHub.

-------------------------------------------------------------------------------------

## Chapters / Topics Covered

1. **Chapter 1: Introduction to Visual C# & GUI Basics**
   * Objects, Classes, and Controls
   * Visual Studio IDE Navigation (Designer, Solution Explorer, Properties, Toolbox)
   * Event-Driven Programming & Event Handlers
   * Working with Controls (Labels, Buttons, PictureBoxes)
   * Syntax Errors, IntelliSense, and Code Formatting

----------------------------------------------------------------------------------------------------------------------

## Chapter 1 Concepts Summary

* **Objects and Classes:** An object is a program component containing data (properties) and operations (methods). A class is the blueprint for an object.
* **Controls & GUI:** Visible UI elements like Button, Label, and TextBox are controls defined by .NET classes.
* **Visual Studio IDE Windows:** Designer, Solution Explorer, Properties Window, and Toolbox.
* **Event-Driven Programming:** GUI applications execute event handlers when users interact with controls.
* **Key Statements:** `MessageBox.Show("Hello World"); and this.Close();.
