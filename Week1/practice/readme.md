### Week1-C# GUI Event Handling Practice

### code aya dulmar kusamenaynaa

1. (Label-Clicked)=>marka labelka click la siiyo waxaa shaqo qabanayo MessageBox.Show() wuxuna soo saraya wixi lagu qoray asaga oo kusoo bandhigayo daaaqad yar oo ay ku qorantahay "  "
2. (Label1.Text)=>waxa uu kuu qabanaya marka uu barnamika la kiciyo inuu ku tusiyo qoralka lagu qoray labelka
3. (this.close())=> wuxuu qabanayaa in uu kuu damiyo barnamijkii kacsanaa
4. (Clear Button) | label1.Text = ""; | Marka la taabo badhanka **Clear** wuxuu tir-tirayaa qoraalka Label-ka iyadoo loo dhiibayo String maran
