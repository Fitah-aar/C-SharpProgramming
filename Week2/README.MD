
 # Chapter 2 Key Concepts
​ * **Data Input & GUI Controls**: Reading user input as text from TextBox controls and learning to manage control focus using Tab Order and Access Keys (&).

​ * **Variables & Primitive Data Types:** Declaring variables specifying types such as int, double, decimal, string, and bool, as well as implicit typing using var.

​ * **Variable Scope:** Distinguishing between local variables (scoped within a method) and class fields (accessible across multiple event handlers).
